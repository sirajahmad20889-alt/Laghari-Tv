# Laghari TV
Original Android IPTV player starter for Android phones and Android TV.

## Included
- Android TV and phone launcher declarations
- Remote-friendly dark interface with focusable navigation
- M3U EXTINF parser
- HTTPS-only Xtream authentication client scaffold
- Media3 ExoPlayer dependencies for playback integration

## Not finished
This is a starter project, not a finished IPTV app. Playlist download/import UI, Xtream
catalog loading, player screen, favorites persistence, EPG/XMLTV, catch-up, subtitles,
multi-audio, downloads, parental controls and device testing remain to be implemented.

Use only playlists, streams and credentials you own or are authorized to access.
